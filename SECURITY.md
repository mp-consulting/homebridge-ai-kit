# Security

This plugin keeps account credentials or device keys and can change devices in your home, so a flaw in it matters.

## Reporting a vulnerability

Please report it privately: use [Report a vulnerability](https://github.com/mp-consulting/homebridge-ai-kit/security/advisories/new)
on the repository's Security tab. Do not open a public issue or pull request for it.

Say what is affected (the version and the part of the project), how to reproduce it, and what an attacker gains. Keep
real passwords, tokens and keys out of the report.

You get an answer within a week. We agree on a fix and a date with you, publish an advisory with the release that
fixes it, and credit you unless you prefer otherwise.

## Supported versions

Fixes go into the latest release. Update to it before reporting, if you can.
