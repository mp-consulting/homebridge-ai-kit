MCP clients

Claude Desktop, Claude Code and Cursor can control Homebridge through the MCP server, either launched by the client (stdio) or served by this plugin over HTTP.

127.0.0.1 keeps it on this machine. 0.0.0.0 exposes it to your network.
Create one in Glass UI. A read-only token blocks changes.
For an https Homebridge UI with a self-signed certificate: its SHA-256 fingerprint. Only that certificate is trusted.
Or a PEM file with the UI's certificate or its CA.
Comma-separated. Only for web pages calling the server; desktop clients, localhost pages and this server's own IP are always allowed.
JSON Lines, secrets hidden, rotated at 5 MB. Extra tokens with read or control access go in mcp.http.clients in the JSON config.
